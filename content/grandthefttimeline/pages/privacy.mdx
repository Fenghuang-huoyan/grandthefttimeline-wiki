This page describes **grandthefttimeline.wiki** only. It is not the privacy policy of REAL PLAYERS, and it is not Steam’s.

## What the site stores

The site is a set of static files. It does not create an account, does not take a password, and does not ask for your Grand Theft Timeline or Steam login. There is no comment box and no newsletter form in this version.

Pages you request are served as ordinary documents. This repository does not add a first-party cookie for tracking.

## Analytics

`analytics.gaId` is an empty string. The base layout loads Google Analytics only when that string is non-empty, so no GA4 tag is emitted.

## Advertising

The Native Banner slot after the quick answer is **on** for grandthefttimeline.wiki. Zone id `e2512aef7c7b99618a4e8e97406165ff` loads from `https://bauval.org/21/e2512aef7c7b99618a4e8e97406165ff` on the homepage and guide pages. No advertising script from another game is included. Adult and sensitive categories stay off. The 404 page does not render a slot.

<Callout kind="note" title="No key from another site">
This repository does not carry a measurement id or an ad zone from any other game site. A future key for grandthefttimeline.wiki would be added only in this domain’s own config.
</Callout>

Steam and the site URL printed on the store page are ordinary outbound links. Their own sites set their own cookies once you leave this one. The support address grandemprise@gmail.com is the address on the Steam page. This wiki does not read that mailbox.

The short version of this note is in the footer under Privacy. Affiliation and trademarks are on the [disclaimer](/disclaimer).
